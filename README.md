# Restaurant Management Website

A full-stack restaurant web application with separate interfaces for customers and staff/admin.

## Overview

Built with ASP.NET MVC, this project provides a customer-facing ordering portal and an admin/staff dashboard for managing menus, orders, and operations.

## Features

**Customer Site**
- Browse menu items and categories
- Place and track orders

**Admin / Staff Site**
- Manage menu items and categories
- Process and update order status
- Staff management dashboard

## Tech Stack

| Layer    | Technology              |
|----------|-------------------------|
| Framework| ASP.NET MVC (C#)        |
| Frontend | JavaScript, HTML, CSS   |
| Database | SQL Server (MSSQL)      |
| Tools    | Visual Studio           |

## Getting Started

### Prerequisites

- Visual Studio 2019+
- SQL Server
- .NET Framework

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/KrisKai/Project-Year-2.git
   ```
2. Open `Project Year 2.sln` in Visual Studio
3. Import the database using the [SQL script](https://drive.google.com/file/d/1ldnjPpfGikTlbcDLWzu76vLSwar5MJku/view?usp=sharing)
4. Update the connection string in `Web.config`
5. Build and run the project
